# Drone-Based Object Detection with RGB, Thermal, and Event Cameras

## Overview
This project focuses on building a drone-based object detection system using RGB, thermal, and event cameras. We aim to capture multi-modal data, process it effectively, and train an object detection model to identify objects with high accuracy under varied conditions.

## Project Goals
1. Build a drone setup with RGB, thermal, and event cameras.
2. Capture multi-modal data for object detection.
3. Process and warp images for alignment across modalities.
4. Train a YOLOv11-based object detection model with augmented datasets.
5. Evaluate the model's performance and refine the pipeline.
